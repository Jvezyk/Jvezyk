# Naju Arte — plataforma de e-commerce

**Tipo:** projeto pessoal em desenvolvimento  
**Área:** desenvolvimento web full-stack  
**Visibilidade do código:** privado

## Contexto

Plataforma de comércio eletrônico voltada à venda de produtos artesanais. O projeto envolve catálogo, experiência de navegação e construção do fluxo de pedidos e pagamentos.

## Tecnologias trabalhadas

- Django e Python no backend;
- Next.js e JavaScript no frontend;
- PostgreSQL para persistência;
- Integração com gateway de pagamento;
- Infraestrutura Linux com Nginx para hospedagem.

## Desafios técnicos

- Organizar as responsabilidades de frontend, backend e persistência;
- Estruturar autenticação e operações relacionadas aos pedidos;
- Integrar um provedor externo de pagamentos e lidar com respostas de erro;
- Planejar segurança, proteção de dados e implantação.

## Status e limites

Projeto em desenvolvimento. A presença de uma integração ou módulo nesta descrição não indica que ele esteja concluído ou disponível em produção.
